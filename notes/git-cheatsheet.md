## Commands used

### Create and switch to a new branch
```
git checkout -b setup/oscarmuya
```


### Stage the changes and view what files are staged
```
git add .
git status
```


### Commit with a message
```
git commit -m "Add README and Git cheat sheet"
```


### Push to remote
```
git push -u origin setup/oscarmuya
```


### Switch to main and pull changes then view the commit history
```
git checkout main
git pull
git log --oneline
```
